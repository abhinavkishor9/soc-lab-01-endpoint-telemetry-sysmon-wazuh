# Investigation Notes

## Objective

Investigate endpoint telemetry generated by normal Windows activity.

---

# Environment

Operating System

- Windows 11

Monitoring

- Sysmon
- Wazuh Agent

Analysis Platform

- Wazuh Dashboard

---

# Activity Generated

Commands executed

```powershell
whoami
hostname
ipconfig /all
ping 8.8.8.8 -n 3
notepad
calc
cmd
```

---

# Investigation Steps

## Step 1

Verified Sysmon service was running.

---

## Step 2

Confirmed Sysmon Operational log contained Process Create events.

---

## Step 3

Verified Wazuh ingested Sysmon telemetry.

---

## Step 4

Located Process Create events.

Collected:

- Parent Process
- Child Process
- Command Line
- Username
- Timestamp
- Process ID

---

## Step 5

Built an endpoint activity timeline.

---

---

# Findings

The observed activity was determined to be benign administrative behavior.

No indicators of compromise were identified.

---

# Lessons Learned

- Endpoint telemetry provides detailed visibility into process execution.
- Parent-child relationships help reconstruct execution flow.
- Legitimate Windows binaries can also be used by attackers, making context essential.
